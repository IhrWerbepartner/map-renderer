### Installation & Prerequisits
- Download and install [Raylib](https://github.com/raysan5/raylib/) 6.x on your system.
- Need a c compiler (can be set in Makefile).


Run `make unoptimized` for a debug build.

Run `make release` for a release build.


### Running
Point the binary at some file you wish to open.
Example: The Austrian government releases a basemap in ESRI-Vector (vtpk) format [here](https://www.data.gv.at/datasets/a73befc7-575f-48cb-8eb9-b05172a8c9e3?locale=de) (around 2.4GiB).
